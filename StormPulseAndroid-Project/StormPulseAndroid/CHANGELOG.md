# Changelog

## 1.0.1 (versionCode 2)
- Added recovery if Android terminates the WebView renderer.
- Improved Safe Browsing handling.
- Updated the WebView user-agent version.
- Expanded CI to run Android lint and unit-test tasks before packaging.

## 1.0.0 (versionCode 1)
- Initial branded WebView wrapper for the live StormPulse Base44 site.
- HTTPS-only navigation, geolocation permission handoff, progress UI, retry UI, and back navigation.
